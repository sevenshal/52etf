# 港股主要指数恐慌贪婪指数

## 支持范围

- `HSI.HK`：恒生指数
- `HSCEI.HK`：恒生中国企业指数
- `HSTECH.HK`：恒生科技指数

## 数据链路

1. Tushare `hk_basic` 同步港股基础信息。
2. Tushare `hk_daily` 按交易日同步全市场未复权行情。
3. 本地比较当日 `pre_close` 和前一交易日原始 `close`，识别拆股、合股、送股及除权参考价跳变。
4. DuckDB 视图 `hk_stock_daily_qfq` 将未来公司行为调整比例反向累乘，生成可比的前复权 OHLC。
5. Tushare `index_global` 同步 HSI 和 HKTECH；HSCEI 允许导入其他来源的日线。
6. 恒生指数公司季度检讨公告作为历史成分及权重锚点。
7. 两次调仓之间，基准权重按每只成分股相对调仓日的复权价格变化漂移并重新归一化。
8. 计算结果写入现有 `etf_fear_greed_clone_history`。

## 复权

当日公司行为调整比例：

```text
event_factor[t] = pre_close[t] / raw_close[t-1]
```

比例与 1 的差小于 0.5% 时按 1 处理，避免舍入误差被识别成公司行为。交易日 `t` 的前复权因子是 `t` 之后所有公司行为比例的乘积，公司行为当天本身不重复调整。

成交额和 Tushare 提供的 `pct_chg` 保持原值。

## 官方权重清单

系统只写入经过结构化和硬校验的 JSON 清单，避免 PDF 表格错列后污染历史计算。格式：

```json
{
  "snapshots": [
    {
      "index_code": "HSTECH",
      "effective_date": "2020-09-07",
      "reference_date": "2020-08-12",
      "source_url": "https://www.hsi.com.hk/static/uploads/contents/en/news/pressRelease/20200814T000000.pdf",
      "source_document": "20200814.pdf",
      "extraction_method": "official_pdf_reviewed",
      "verified": true,
      "constituents": [
        {
          "code": "3690",
          "name": "MEITUAN-W",
          "free_float_factor": 65,
          "weight": 8.0
        }
      ]
    }
  ]
}
```

校验要求：

- 自动流程必须同时提取 HSI、HSCEI 和 HSTECH，且每个指数只有一个快照；
- 自动流程要求每个快照权重之和在 99.5%–100.5%，不会自动补齐或归一化缺失权重；
- 同一快照不能有重复代码；
- 港股代码统一为五位数 `.HK`；
- 只有 `verified=true` 的快照参与计算；
- 生效日使用公告指定的正式生效日，不能使用公告日或参考日。
- 生效日必须晚于数据库已有快照，三条指数的生效日必须一致；
- 成分数量必须处于指数合理范围，与上一期成分重合度不得低于 70%；
- 新纳入成分必须先成功补齐 900 天行情，之后才发布权重快照。

### DeepSeek 自动处理

每天的港股基础数据任务会检查恒生指数公司最近 45 天内周五发布的官方新闻稿，
并兼容项目保存的历史检讨日期。下载后先用确定性文本检查确认文档是指数检讨公告，
再以 SHA-256 和 `source_document` 去重。

新 PDF 先在本地提取全文文本，再连同固定 JSON Schema 一起发给 DeepSeek（API Key 使用
AI 选股页面的 DeepSeek 配置），模型只返回候选 JSON，不能访问或写入数据库。候选结果会保存
来源页码、DeepSeek 原始输出日志和官方 URL，随后由后端执行上述硬校验。任何一项失败都会
保留原权重并让定时任务明确失败；全部通过后才补齐新增成分历史行情，并在一个短事务内导入权重。

## 七个分项

1. 指数相对 125 日均线的市场动量。
2. 漂移权重加权的成分股 252 日高低区间位置。
3. 漂移权重和成交额加权的上涨广度。
4. HKEX 指数期权 PCR；本地历史不足时缺失。
5. 20 日指数实现波动率相对 50 日均值。
6. 港股指数 20 日收益减 TLT 20 日收益。
7. FRED 美元高收益债 OAS 减投资级债 OAS后取反。

每个分项使用 252 日滚动 z-score 和正态 CDF 映射到 0–100。首版至少五项有效才产出总分；缺失分项不填 0 或 50。这样在 HKEX 期权和较早期美元信用利差缺失时，仍可使用市场内部五项计算，并在结果中明确保存实际参与分项。

## 定时任务

### 港股基础数据同步

任务键：`hk_stock_base_data_sync`

当前 Tushare 账号 `hk_daily` 频率为每分钟一次。日常任务默认每次同步一个缺失交易日。历史回填可提高“单次行情天数”，任务会按接口间隔低速续跑。

权重参数：

- 开启“下载官方检讨公告”可缓存2020年以来的季度 PDF；
- “权重清单路径”用于导入已复核 JSON；
- “DeepSeek自动处理新检讨”默认开启，模型与 API Key 复用 AI 选股服务的 DeepSeek 配置；
- 公告发现窗口默认 45 天；
- PDF 下载、DeepSeek 解析、硬校验和权重入库相互分离，模型不能直接写生产数据库。

### 港股指数贪恐回跑入库

任务键：`hk_index_fear_greed_backfill`

基础行情和权重同步完成后运行。每个指数独立计算；某个指数缺数据不会阻断其他指数。
