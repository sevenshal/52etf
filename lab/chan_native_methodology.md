# 自有缠论结构回测方法（研究版）

> 引擎版本 v2（`chan_native.py`）：中枢改为固定区间状态机 + 真实 GG/DD + 级别标签；线段区分第一/第二种划分；一买/一卖背驰改用 MACD 面积（盘整/趋势）。旧版行为见 git 历史。

## 目标

不依赖 CZSC 的买卖点输出，按从左到右回放 OHLC 数据，输出可审计的分型、笔、线段、中枢和三类买点。每个结构必须带确认时间；回测只在确认后下一根 1m 开盘成交。

## 结构口径

1. **包含关系**：逐根合并，合并方向由最近非包含区间确定。
2. **分型**：合并K线的三K分型，右侧K线出现后才确认。
3. **笔**：分型交替、最小合并K线间隔为4；同标记分型只保留更极值者。
4. **线段**：至少三笔；上涨线段检查向下笔特征序列，下跌线段检查向上笔特征序列。特征序列先做包含处理。
   - **第一种划分**：特征序列顶/底分型的第一、第二元素之间**无缺口**——出现分型即确认线段结束。
   - **第二种划分**：第一、第二元素之间**有缺口**——只记为 pending，需再有三笔完成且价格未重新收复破坏前极值才确认；期间若同向笔创出新极值则 pending 作废、线段继续。
   - 直接笔破坏（价格越过线段起点）始终按第一种立即确认。末尾未完成线段不输出。
5. **中枢**：前三个连续单元（线段，缺线段时退化为笔）重叠形成**固定区间** `[ZD, ZG] = [max(低3), min(高3)]`，成形后不再收缩。
   - 后续单元与固定区间相交则**延伸**，同时更新真实极值 `GG = max(全部高)` / `DD = min(全部低)`；首个不相交单元记录破坏确认点、破坏笔序号和破坏方向。
   - `classify_center_relations` 按相邻中枢的 GG/DD 关系标注 `trend`（`up`/`down`/`range`）和 `growth`（`newborn`/`expansion`）；不改动区间。
   - `level`：基础层为 0，`recursive_levels` 为每个更高层的中枢赋对应层号。
6. **一买/一卖**：必须先有底/顶候选中枢；确认的同向 `a`、`b` 两段中，`a` 真正跌破/突破中枢固定边界（一买 `a.low < ZD`），`b` 越过 `a` 创新低/新高，且 `b` 相对 `a` 出现 **MACD 面积背驰**（`area(b) < area(a)`，两者均 > 0）。`a` 之前有 ≥2 个同类中枢且 GG/DD 单调时记为**趋势背驰**，否则**盘整背驰**。未提供 K 线时退化为“位移效率下降 + 振幅或绝对位移至少再降一项”的旧口径。
7. **二买/二卖**：离开中枢但仍有部分重叠的走势，首次反向回调/反抽不破前低/前高，再由同向线段确认。
8. **三买/三卖**：离开段整体站上/跌破中枢，回试最低/最高点不重新回到中枢，再由同向线段确认。
9. **离开与重复信号**：中枢记录首次破坏的线段索引和方向；离开段必须就是该已确认破坏线段。同一中枢、同一类型只认第一次完整离开—回试—确认，避免把后续每次上行/下行重复计为新的二/三买卖。

## 未来函数约束

- 原始分型必须等待右侧K线；
- 线段必须等待特征序列破坏确认；
- 日线/30m过滤只读取信号时间之前最后一根已完成的高周期K线；
- 同一股票、同一交易日、同一买点只保留最早确认事件。

## 当前未完成项

- 中枢已是固定区间状态机（延伸/新生/扩展 + 级别标签），但“3 个同级别中枢连成趋势后整体升级为更高级别中枢”仍依赖 `recursive_levels` 的递归提升，尚未有独立的同级别升级状态机；仍需更多人工结构样本核对中枢级别对应关系；
- 背驰已改用 MACD 面积并区分盘整/趋势背驰，但趋势背驰只比较相邻同类中枢的 GG/DD 单调性，尚未做完整走势级别的中枢区间套比较；
- 一买/一卖为“中枢固定边界突破 + 同向创新 + MACD 面积背驰”，属于可审计研究口径，不等同于所有流派的背驰定义；
- 当前结果是研究基线，不应直接用于实盘。

## 当前数据

候选池由历史 `a_stock_index_weight` 成分快照直接展开为有效区间，剔除 ST 和流动性不足标的；不再从旧信号样本反推股票池。中证2000只接受正确代码 `932000.CSI`，不能用 `000932.SH` 替代。数据库内置快照目前主要覆盖沪深300和中证500；中证1000/中证2000的真实历史快照已由 `sync_chan_index_weights.py` 导出为 `csi_missing_weights.csv`，回测通过 `--supplemental-weights` 读取。最新扩展统计见 `native_chan_1m_t1_summary_csi2000.csv`。

标准 CZSC 回测脚本默认保持原三指数配置；需要扩展中证2000时显式使用 `--include-csi2000`，并提供数据库或 `--supplemental-weights` 中的 `932000.CSI` 历史快照。缺失指数不会自动用相近指数替代。

## 严格版最近一次全量快照（2026-02-01—2026-08-28）

实际纳入 1296 只历史成分（当前库只有沪深300/中证500），1m、T+1 收盘退出、扣除 15/25bp 交易成本：一买 9 笔（平均 +1.24%，胜率 66.7%），二买 9 笔（平均 -0.30%，胜率 44.4%），三买 111 笔（平均 -1.02%，胜率 36.0%）。一买/二买样本仍很少，不能据此宣称策略有效；三买的负表现说明中枢离开与级别确认仍需继续核验。
严格递归日线+30m过滤在该区间没有形成可用交集，统计为0笔；这表示当前历史窗口的高级别结构样本不足，不是把0笔解释成“过滤后无风险”。

## 扩展候选池快照（Tushare历史成分）

已通过本机配置的 Tushare 账号获取真实历史快照并生成 `csi_missing_weights.csv`：中证1000为19个调仓快照、每次1000只；中证2000为19个调仓快照、每次2000只，覆盖 2025-01-27—2026-07-31。扩展池回测共4434只历史成分，468个去重事件：一买43笔（平均 +0.34%，胜率41.9%），二买33笔（平均 +0.33%，胜率57.6%），三买391笔（平均 -1.22%，胜率30.4%）。加入日线历史预热后，日线方向过滤分别为22/14/177笔；30m+日线普通方向过滤为0/0/8笔。严格递归日线+30m交集仍为0笔，不能据此评价过滤效果。
