# logvol_distribution.md — log(成交量) 分布分析：0.25σ 缩量 vs 1.25σ 放量的统计合理性

## 问题
放量用 1.25σ、缩量用 0.25σ，不对称。0.25σ 在标准正态下 P(Z<-0.25)=40.1%，"几乎没置信度"。
检验 log(成交量) 是否正态、log_z（信号实际用）的经验分布。

## 数据
- `log_vol = log(volume)` 原始序列；`log_z = (log_vol - 前20日均) / 前20日std`（回测实际用的量）
- 标：510880(红利)/588000(科创50)/512480(半导体)/159941(纳指)/518880(黄金)/QQQ
- 区间 2023-03-22 ~ 2026-08-14

## log_vol 原始分布（偏度/超额峰度）

| 标的 | 偏度 | 超额峰度 | 正态? |
|---|---|---|---|
| 510880 红利 | +0.21 | -0.20 | 接近 |
| 588000 科创50 | **+0.92** | **+1.94** | 明显正偏+尖峰（规模增长趋势） |
| 512480 半导体 | +0.36 | +0.46 | 接近 |
| 159941 纳指 | +0.16 | +0.15 | 几乎正态 |
| 518880 黄金 | +0.34 | -0.09 | 接近 |
| QQQ | -0.10 | +0.17 | 几乎正态 |

→ log(vol) 大体接近正态（这正是 log 变换的意义），但非严格：588000 因 ETF 上市扩容趋势正偏明显。

## log_z 经验分布（关键）

所有标的正偏（+0.15~+0.66）+ 尖峰（+0.33~+1.92）：**右侧（放量）尾部比正态厚，左侧（缩量）尾部比正态薄**。
Q-Q 对照（510880）：p=0.10 实际 -1.53 vs 正态 -1.28（左尾薄）；p=0.90 实际 +1.49 vs 正态 +1.28（右尾厚）。

| 阈值 | 实际分位数 | 正态分位数 | 含义 |
|---|---|---|---|
| -0.25σ | **~44%** | 40.1% | 44% 的日子算"缩量"，确实宽松 |
| -0.50σ | ~37% | 30.9% | |
| -0.75σ | ~33% | 22.7% | |
| +1.25σ | **~85%**(右尾15%) | 89.4%(10.6%) | 放量日比正态更多 |

## 结论

1. **用户质疑成立**：-0.25σ 在经验分布里对应 ~44% 分位（比正态 40% 还宽松），**接近一半的交易日都满足"缩量"**，确实没有统计置信度。log(量) 也不是严格正态（右偏+尖峰）。

2. **但缩量 0.25σ 的合理性与"统计检验"无关**——它是**多条件组合里的时序确认**：
   - 买入已由「恐贪≤25（尾部事件）+ 放量≥1.25σ（右尾 15% 事件）」双重确认
   - 「贪恐≥70」本身已是强条件（历史上只在主升浪后出现）
   - 缩量只是**确认动能衰竭**：不需要统计显著性，只要"量能不再放大"（44% 分位足够）
   - 回测验证：0.25/0.5/0.75σ 收益 300.3%/291.5%/291.5% 相近 → 不是精确依赖 0.25

3. **不对称合理**：放量条件要严（1.25σ），因为放量日很多（右尾厚，假信号多）；
   缩量条件要松（0.25~0.75σ），因为"等缩量"的目的只是晚卖几天、避开放量中的过早卖出。

4. 若想更"统计上体面"：用 0.5~0.75σ（P≈31-33%），收益仅差 ~9pp（291.45% vs 300.30%），
   但 x=0（P=50%）实测最差（207%）——缩量确认太宽松（上涨中继正常波动也卖）反而不行。
